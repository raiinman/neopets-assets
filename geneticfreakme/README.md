# Geneticfreakme User Lookup V6

Production assets and profile code for the moonlit faerie-harbor lookup.

- `lookup-hero-v6.jpg` — fixed-ratio harbor hero with the three-faerie centerpiece and empty identity plaque.
- `lookup-trophy-v6.jpg` — fixed-ratio empty trophy-alcove background, repeated vertically behind the real trophy module.
- `lookup-v6.html` — paste-ready Neopets User Lookup HTML/CSS.
- `lookup-v6-production.html` — exact minified copy currently deployed to Neopets.
- `lookup-v5-backup.html` — exact pre-V6 profile code retained for rollback.

The two raster assets are proportional crops from the approved V6 concept. They are never stretched independently on either axis.

The live lookup keeps Neopets' real user, collection, shop, trophy, and pet data in the native modules. The custom code only lays those modules out and styles their containers.
